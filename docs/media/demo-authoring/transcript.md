# Loci local demo and authoring walkthrough

This 40.7-second video is silent. The headings and pointer demonstrate the
following actions on the generated sample cube. The written
[authoring guide](../../demo-authoring.md) provides setup, detailed steps and cleanup.

| Time | Demonstrated action |
| --- | --- |
| 0.0–7.6s | Rotate the cube in the public reader and select its Top edge annotation. The linked chapter plays while the chosen model view remains in place. |
| 7.6–13.1s | In Analysis, select the sample video and set its range to 0–4000 milliseconds. |
| 13.1–16.9s | Map the range to 3D and click the cube's surface to capture a placement point. |
| 16.9–20.6s | Enter the title “Blue square” and create the private annotation. |
| 20.6–25.6s | Refine the point on the front face and save the annotation. |
| 25.6–30.2s | Open the private preview and review the front-face chapter, selected range and transcript. |
| 30.2–34.2s | Publish this annotation using its individual publication control. |
| 34.2–40.7s | Open the public evidence page and select “Blue square” to verify the model pin and 0–4 second playback window. |

The demo code improvements and video are a 3D Humanities Lab contribution.
