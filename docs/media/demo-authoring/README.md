# Local demo video

The **3D Humanities Lab** contributed the local demo code improvements and
this video. It records the generated sample cube and single-range authoring
workflow in a disposable local Loci installation. The model, twelve-second
evidence video, transcript and demonstration annotations are original generated
content. The recording contains no research collection media or participant
records.

- [Watch or download the walkthrough](loci-demo-authoring.mp4)
- [Read the timed text description](transcript.md)
- [Follow the current authoring guide](../../demo-authoring.md)

The video is silent, 1920×1080, 30 frames per second and 40.7 seconds long.
On-screen instructions and a moving pointer identify the actions. It was
assembled from the Lab's October 4, 2026 demo captures. The complete viewport
stays visible; no interface elements were fabricated. The guide gives the
current setup and cleanup steps. The opening reader overview precedes the
correction of the sample Top edge pin described in [the refresh guide](../../../examples/README.md#refresh-the-generated-sample-in-an-existing-installation).
